# Trellis demos

Each milestone ends with a demo that runs start to finish.

| Milestone | Demo | Run |
|---|---|---|
| M1 | [Three keys](M1.md): every call needs three yeses | `trellisd demo three-keys` |
| M2 | [Who allowed this?](M2.md): trace a deny to its grant, then catch a ledger edit | `trellisd demo who-allowed-this` |
| M3 | [The catalog says pii](M3.md): a catalog tags a column and the next query is masked | `trellisd demo catalog-says-pii` |

The `docker compose up` quickstart arrives in M6.
